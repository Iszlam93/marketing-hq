## 2. Pricing and motion

- Shows: Free $0 (light quota, unlimited Tab completions); Pro $20/mo; Max $200/mo; Teams $80/mo + $40/mo per full seat (up to 200 users); Enterprise custom ("Let's talk"). https://devin.ai/pricing
- Shows: Pricing page uses "quota/usage allowance", not ACUs. Assumes: ACU pricing has been retired from the public page (the old ACU model is not shown now); confirm in docs.
- Shows: Enterprise adds SAML/OIDC SSO, dedicated account management, VPC/dedicated deployment, custom terms. https://devin.ai/pricing
- Assumes: Hybrid motion. Product-led for individuals and small teams (free + $20 + download); sales-led for enterprise (demo, Trust Center, FDEs, guarantee, AWS Marketplace).
- Shows: Devin Desktop is the new name for Windsurf, built on the Windsurf IDE; plans and pricing carry over; Windsurf for JetBrains remains. Claims "Over 1M users and over 4,000 enterprise customers". https://devin.ai/desktop
- Assumes: Desktop is the low-friction developer on-ramp that feeds the cloud agent (hand-off between local and cloud sessions).

## 5. Who the GTM is aimed at

- Assumes: Two layers. Developer layer (Free/Pro, Desktop download, CLI, "Switch from Cursor", Claude Code comparison) and enterprise/CIO-CISO layer (Trust Center, FedRAMP, guarantee, FDEs, ROI dashboards, AWS Marketplace, bank logos). Engineering leader is the bridge buyer (cost controls, productive-hours dashboards).
- Shows: Sites name no job titles, apart from "Forward Deployed Engineers" (their own staff). Assumes: buyer persona is implied (eng leaders), not named.
- Assumes: Message is fairly consistent: "autonomous engineer", cost efficiency ("up to 60% less", "40% more cost-efficient"), security/governance. Inconsistency: brand split between Devin (agent), Windsurf/Desktop (IDE) and Cognition; naming shifted in 2026, pricing page omits Windsurf while the Desktop page explains it.
- Assumes (for Kimchi): Devin's cost-efficiency and "use the best model per step" claims overlap Kimchi's territory; the guarantee shifts risk to the vendor and sets a bar for outcome proof.
