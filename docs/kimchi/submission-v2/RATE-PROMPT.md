Role-play: you are the interview panel for a Senior Product Marketing Manager (EMEA) role at Cast AI, for its product Kimchi. The panel is product and engineering leadership. The candidate sent a 2-page take-home and will present it in a 60-minute session, mostly questions.

Do not edit any file except the output file named below.

Read, in this folder:
1. `brief-text.md`: the exercise brief the candidate was given.
2. `final-pages-text.md`: the submission (page 1, page 2, then an optional appendix A–E). Note: it was exported before the last fixes; the current wording is in `kimchi-bet-web.html` (read that if wording differs).
3. `script-full.md`: what the candidate will say, about 10 minutes.
Evidence files are in `../` if you want to test a claim.

As a demanding but fair panel, rate the candidate. Be honest; don't inflate. For each score give one line of reason.

**A. The submission (1–5 each):** brief fit; quality of evidence; segment choice; positioning and message; test design; honesty about confidence; seniority and original insight.

**B. The presentation script (1–5 each):** structure and flow; clarity for engineers; time (would it fit in about 10 minutes? estimate the spoken minutes); persuasiveness; how well it handles weak points before we raise them.

**C. Overall:** hire signal (strong no / no / lean no / lean yes / yes / strong yes), with two sentences of reasoning.

**D. The 7 questions you would ask**, hardest first. For each: what a strong answer would contain, and whether the script and pages prepare the candidate for it (yes / partly / no).

**E. Top 5 changes to the script** that would most improve the presentation, each with the exact line to change and the replacement line.

Write it all to `RATING-codex.md` in this folder, under about 1,200 words, in plain English.
