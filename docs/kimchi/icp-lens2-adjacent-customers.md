# ICP lens 2: who pays for tools adjacent to Kimchi (unbiased re-run)

## 1. Method

- Searched 23 Oct 2026, public web only. No finance-specific searches for Part A.
- For each vendor, took the vendor's full published customer/case-study list, then opened story pages to read the industry as the page states it.
- Only named customers count. Unnamed ones are listed separately and excluded from counts.
- Industry comes from the story page or the customer's own one-line description on it. If absent: "not stated", group Unclear. No outside knowledge used.
- Groups are my mapping of the stated wording: Finance / Tech-software / Government-defence / Other / Unclear. Borderline mappings are noted.
- Limit: up to 25 pages opened per vendor. Cognition had 42 named entries, so 17 were not opened (counted Unclear).
- Part A is a count of vendor-published stories, which is not spend.

## 2. Part A tables

Columns: Customer | Industry (as stated) | Group | HQ if stated | Type | Source | Primary/Secondary. All rows are Primary (vendor's own page) unless noted.
