# The ad checklist

Fill one row per ad. Use the same columns and the same theme list for every competitor, so the comparison is fair.

## Before you start: fix the theme list
Write 5 to 8 short themes **before** reading any ads, from what buyers care about (for example: save time, save money, fewer mistakes, easy to start, security, works with your tools, proof from customers). You can add themes while reading, but mark them "added".

## One row per ad
| Field | What to write |
|---|---|
| Competitor | name |
| Channel and country | for example "LinkedIn, UK" |
| Collected on | date |
| Ad ID or link | if the library shows one |
| Format | image / video / carousel / text / other |
| Main promise | headline or first line, under 15 words, word for word |
| Problem named | the pain it points at, in a few words, or "none" |
| Speaks to | the role or type of buyer, if clear |
| Proof | numbers, customer logos, awards, ratings, or "none" |
| Offer | demo / free trial / download / webinar / discount / other |
| Call to action | the button or last line |
| Started | start date shown in the library |
| Still running | yes / no |
| Versions | how many near-identical versions you can see |
| Theme | one or two from your fixed list |

## Per competitor and channel
| Field | What to write |
|---|---|
| Active ads | total count shown, even if you read only some |
| Read | how many you filled rows for, and how you chose them (all, newest 15, longest running) |
| Oldest active ad | start date |
| New in last 4 weeks | count |

## Paste format (for Route B)
When you paste screenshots or text, add one line on top:
`Competitor: <name> · Channel: <channel> · Country: <country> · Collected: <date> · Active ads shown: <number>`
