# What to note for each ad

| Field | What to write |
|---|---|
| Competitor | name |
| Platform | LinkedIn / Google / Meta / TikTok / other |
| Country | the country the library was set to |
| Period | the time period chosen (running now, last 30 days, last 90 days, last 12 months) |
| Checked on | date |
| Ad link | the library's link to this ad, if shown |
| Format | image / video / carousel / text / other |
| Headline | headline or first line, word for word, under 15 words |
| What it is about | the theme in 2 to 4 words (for example "AI for sales teams") |
| Problem named | the pain it points at, or "none" |
| Speaks to | the role or type of buyer, if clear |
| Proof | numbers, customer logos, awards, ratings, or "none" |
| Offer | demo / free trial / download / webinar / event / discount / other |
| Call to action | the button text |
| Started | start date shown in the library |
| Still running | yes / no |
| Versions | how many near-identical versions you can see |

**Themes:** keep the "What it is about" labels short and reuse the same label for the same idea, so the summary can count them.

**Per platform:** also note the total number of active ads shown, and how many you read.
